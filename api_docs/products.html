Products & Hardware Variants API

Public Path: /api/v1/products • Admin Path: /api/v1/admin/products

Controllers: ProductCatalogController (Public) & AdminProductController (Admin)

Architecture & Variant Relationship Model

The product catalog utilizes a unified SKU-based relationship model:

  • Product Entity: Retains core identity, unique sku, optional parentSku, productName, slug, brandId, category mappings, and pricing/stock summary bounds.
  • Variant Linking (isVariantOf): Products link to family variants via parentSku. Querying any product resolves its family root and recursively traverses all connected siblings and children (DFS resolution).
  • Auto-slug Generation: If slug is omitted during creation, it defaults to the SKU with spaces replaced by hyphens.
  • ProductVariant Entity: Holds physical inventory details (SKU, thumbnail URL, Markdown description, media album UUIDs, JSONB hardware specs, listPrice, salePrice, and stock counts).

1. Public: List Active Products

Lists active store products with search keyword, category, and brand filters.

  • Method: GET
  • Path: /api/v1/products
  • Security: Public (permitAll)

Query Parameters

Parameter Type Required Description
search string No Search keyword across product name, SKU, or slug
categoryId integer No Filter by category ID
brandId integer No Filter by brand ID

2. Public: Get Product by ID or Slug

  • Method: GET
  • Paths: /api/v1/products/{id} or /api/v1/products/slug/{slug}
  • Security: Public (permitAll)

Success Response (200 OK)

Returns a single ProductResponse object.

3. Admin: List All Products

Lists all products including draft and inactive items.

  • Method: GET
  • Path: /api/v1/admin/products
  • Security: Requires CATALOG_READ or CATALOG_WRITE
  • Query Parameters: search, categoryId, brandId, isActive

Success Response (200 OK)

Returns array of ProductResponse objects.

4. Admin: Create Product

Creates a product and provisions an initial default variant.

  • Method: POST
  • Path: /api/v1/admin/products
  • Security: Requires CATALOG_WRITE

Request Body

{
  "productName": "ASUS ROG Strix G16",
  "sku": "SKU-ROG-G16-01",
  "parentSku": null,
  "slug": "asus-rog-strix-g16",
  "brandId": 1,
  "categoryIds": [1, 2],
  "primaryCategoryId": 1,
  "isActive": true,
  "thumbnailUrl": "/uploads/products/rog_g16.webp",
  "description": "# ASUS ROG Strix G16 Gaming Laptop",
  "listPrice": 45000000.00,
  "salePrice": 42000000.00,
  "stockQuantity": 12
}

Success Response (201 Created)

Returns created ProductResponse.

5. Admin: Update Product

Updates product details, SKU, parentSku, brand, pricing, and category mappings.

  • Method: PUT
  • Path: /api/v1/admin/products/{id}
  • Security: Requires CATALOG_WRITE
  • Path Variable: id (UUID)

Request Body

{
  "productName": "ASUS ROG Strix G16 2026",
  "sku": "SKU-ROG-G16-01",
  "parentSku": null,
  "slug": "asus-rog-strix-g16",
  "brandId": 1,
  "categoryIds": [1, 2],
  "primaryCategoryId": 1,
  "isActive": true,
  "listPrice": 44000000.00,
  "salePrice": 41500000.00,
  "stockQuantity": 15
}

Success Response (200 OK)

Returns updated ProductResponse.

6. Admin: Toggle Product Status & Delete Product

  • Toggle Status: PATCH /api/v1/admin/products/{id}/status • Body: {"isActive": false} → 204 No Content
  • Delete Product: DELETE /api/v1/admin/products/{id} → 204 No Content (Cascades variants and category join tables)

7. Admin: Product Variant Sub-Resource Endpoints

  • List Variants: GET /api/v1/admin/products/{productId}/variants → 200 OK (Array of ProductVariantSummary)
  • Create Variant: POST /api/v1/admin/products/{productId}/variants → 201 Created
  • Update Variant: PUT /api/v1/admin/products/{productId}/variants/{variantId} → 200 OK
  • Delete Variant: DELETE /api/v1/admin/products/{productId}/variants/{variantId} → 204 No Content

8. Admin: Export Products CSV

Generates and downloads a CSV export file with UTF-8 BOM encoding containing filtered or all products.

  • Method: GET
  • Path: /api/v1/admin/products/export
  • Security: Bearer JWT (CATALOG_READ or CATALOG_WRITE)
  • Produces: text/csv; charset=UTF-8

Query Parameters

Parameter Type Required Description
search String No Keyword search on product name, SKU, parent SKU, or slug
categoryId Integer No Filter by specific category ID
brandId Integer No Filter by specific brand ID
isActive Boolean No Filter by active/inactive status
