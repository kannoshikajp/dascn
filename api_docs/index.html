  • CORS Allowed Origins:
    • http://localhost:3000, http://localhost:8888, http://127.0.0.1:3000, http://127.0.0.1:8888

Authentication & Security Architecture

Stateless JWT Specification

  • Library: Nimbus JOSE with HmacSHA256 (256-bit symmetric key).
  • Header format: Authorization: Bearer <accessToken>
  • JWT Payload Claims: 
    {
  "sub": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "role": "ROLE_ADMIN",
  "permissions": [
    "AUTH_ME",
    "AUTH_CHANGE_PASSWORD",
    "USER_MANAGE",
    "ROLE_MANAGE",
    "CATALOG_READ",
    "CATALOG_WRITE"
  ],
  "iss": "joppe-backend",
  "iat": 1729584000,
  "exp": 1729670400
}

Common Response Formats

1. Standard Operation Result (ApiResponse)

{
  "success": true,
  "message": "Operation completed successfully"
}

2. Global Error Response (ErrorDetails)

Returned for HTTP 400, 401, 403, 404, 500:

{
  "status": 403,
  "error": "Forbidden",
  "message": "Access denied: insufficient permissions",
  "timestamp": "2026-10-31T08:30:00.000Z"
}

3. Field Validation Error Response

Returned on HTTP 400 when standard Bean Validation (@Valid) constraints fail:

{
  "status": 400,
  "error": "Bad Request",
  "message": "Validation failed",
  "fieldErrors": {
    "email": "Email must be a valid email address",
    "password": "Password must be at least 6 characters"
  },
  "timestamp": "2026-10-31T08:30:00.000Z"
}

HTTP Status Code Conventions

Status Code Meaning Usage Scenario
200 OK Success Standard successful GET, PUT, or PATCH operation returning payload body
201 Created Resource Created Successful POST registration, user creation, product, variant, order placement, or receipt
204 No Content Action Succeeded Successful DELETE or PATCH status toggles with no return body
400 Bad Request Client Error Malformed JSON, schema validation failure, business validation failure
401 Unauthorized Missing / Invalid Auth Missing Bearer token, expired JWT, or invalid credentials
403 Forbidden Access Denied Authenticated user lacks required permission or account is deactivated
404 Not Found Not Found Target entity UUID or slug not found in database
500 Server Error Internal Error Unhandled runtime exception or database connectivity degradation
