Customer Address Book API

Base Path: /api/v1/addresses

Controller: joppe.backend.domain.user.UserAddressController

Security: Requires ADDRESS_MANAGE authority. User identity resolved from JWT subject.

1. List Shipping Addresses

Lists all saved delivery addresses for the authenticated customer.

  • Method: GET
  • Path: /api/v1/addresses
  • Security: Requires ADDRESS_MANAGE

Success Response (200 OK)

[
  {
    "id": "33333333-4444-5555-6666-777777777777",
    "userId": "a50c82f8-0f0e-436b-a253-12502690d796",
    "recipientName": "Nguyen Van A",
    "recipientPhone": "0901234567",
    "streetAddress": "123 Tech Street",
    "ward": "Ward 1",
    "district": "District 3",
    "province": "Ho Chi Minh City",
    "isDefault": true,
    "createdAt": "2026-10-22T08:00:00.000Z"
  }
]

2. Get Address by ID

  • Method: GET
  • Path: /api/v1/addresses/{id}
  • Security: Requires ADDRESS_MANAGE (ownership verified)
  • Path Variable: id (UUID)

Success Response (200 OK)

Returns a single AddressResponse object.

3. Add Shipping Address

Adds a new delivery address to the customer's address book.

  • Method: POST
  • Path: /api/v1/addresses
  • Security: Requires ADDRESS_MANAGE

Request Body

{
  "recipientName": "Nguyen Van A",
  "recipientPhone": "0901234567",
  "streetAddress": "123 Tech Street",
  "ward": "Ward 1",
  "district": "District 3",
  "province": "Ho Chi Minh City",
  "isDefault": true
}

Success Response (201 Created)

Returns created AddressResponse.

4. Update Shipping Address

  • Method: PUT
  • Path: /api/v1/addresses/{id}
  • Security: Requires ADDRESS_MANAGE
  • Path Variable: id (UUID)

Success Response (200 OK)

Returns updated AddressResponse.

5. Set Default Address & Delete Address

  • Set as Default: PATCH /api/v1/addresses/{id}/default → 204 No Content
  • Delete Address: DELETE /api/v1/addresses/{id} → 204 No Content
