Admin — Inventory & Supply Chain API

Base Path: /api/v1/admin/inventory

Controller: joppe.backend.admin.controller.AdminInventoryController

Security: Requires INVENTORY_READ (viewing) or INVENTORY_WRITE (modifications)

1. Suppliers Management

CRUD operations for hardware distributors, component manufacturers, and vendor contacts.

  • List Suppliers: GET /api/v1/admin/inventory/suppliers (Supports isActive, search) → 200 OK
  • Get Supplier by ID: GET /api/v1/admin/inventory/suppliers/{id} → 200 OK
  • Create Supplier: POST /api/v1/admin/inventory/suppliers (Security: INVENTORY_WRITE) → 201 Created
  • Update Supplier: PUT /api/v1/admin/inventory/suppliers/{id} (Security: INVENTORY_WRITE) → 200 OK
  • Toggle Active Status: PATCH /api/v1/admin/inventory/suppliers/{id}/status?isActive=true → 204 No Content
  • Delete Supplier: DELETE /api/v1/admin/inventory/suppliers/{id} → 204 No Content

2. Goods Receipts (Inbound Stock Import)

Manages physical inventory batches received from suppliers.

  • List Receipts: GET /api/v1/admin/inventory/receipts (Supports status, supplierId, search) → 200 OK
  • Get Receipt Detail: GET /api/v1/admin/inventory/receipts/{id} → 200 OK (Includes line items and unit costs)
  • Create Inbound Receipt Batch: POST /api/v1/admin/inventory/receipts (Security: INVENTORY_WRITE) → 201 Created
  • Finalize Draft Receipt: POST /api/v1/admin/inventory/receipts/{id}/complete (Security: INVENTORY_WRITE) → 200 OK

3. Warehouse Stock & Low Stock Audits

Real-time visibility over physical quantity on hand, reserved items, available units, and safety stock reorder thresholds.

  • List Stock Audits: GET /api/v1/admin/inventory/stock (Supports lowStockOnly, search, categoryId, brandId) → 200 OK
  • Adjust Stock Manually: PATCH /api/v1/admin/inventory/stock/{variantId} (Security: INVENTORY_WRITE) → 200 OK
