Category Management API

Public Path: /api/v1/categories • Admin Path: /api/v1/admin/categories

Controllers: CategoryController (Public) & AdminCategoryController (Admin)

1. Public: Get Active Category Tree

Returns active categories structured as a nested parent-child tree.

  • Method: GET
  • Path: /api/v1/categories/tree
  • Security: Public (permitAll)

Success Response (200 OK)

[
  {
    "id": 1,
    "parentId": null,
    "categoryName": "PC Components",
    "slug": "pc-components",
    "iconUrl": "https://cdn.joppe.vn/icons/cpu.svg",
    "isActive": true,
    "productCount": 42,
    "children": [
      {
        "id": 2,
        "parentId": 1,
        "categoryName": "Graphics Cards (GPU)",
        "slug": "gpu",
        "iconUrl": "https://cdn.joppe.vn/icons/gpu.svg",
        "isActive": true,
        "productCount": 18,
        "children": []
      }
    ]
  }
]

2. Public: Get Category by ID or Slug

  • Method: GET
  • Paths: /api/v1/categories/{id} or /api/v1/categories/slug/{slug}
  • Security: Public (permitAll)

Success Response (200 OK)

Returns single CategoryResponse object.

3. Admin: List Flat Categories

Returns flat category list with product count, child count, search query, and status filters.

  • Method: GET
  • Path: /api/v1/admin/categories
  • Security: Requires CATALOG_WRITE authority

Query Parameters

Parameter Type Required Description
search string No Search keyword matching category name or slug
isActive boolean No Filter by active status (true or false)

Success Response (200 OK)

[
  {
    "id": 1,
    "parentId": null,
    "parentName": null,
    "categoryName": "PC Components",
    "slug": "pc-components",
    "iconUrl": "https://cdn.joppe.vn/icons/cpu.svg",
    "isActive": true,
    "createdAt": "2026-10-22T00:00:00.000Z",
    "productCount": 42,
    "childCount": 6
  }
]

4. Admin: Create Category

Creates a new catalog category. Generates URL slug automatically if omitted.

  • Method: POST
  • Path: /api/v1/admin/categories
  • Security: Requires CATALOG_WRITE

Request Body

{
  "parentId": 1,
  "categoryName": "Solid State Drives (SSD)",
  "slug": "solid-state-drives-ssd",
  "iconUrl": "/uploads/categories/ssd.svg",
  "isActive": true
}

Success Response (201 Created)

Returns created CategoryResponse object.

5. Admin: Update Category

Updates category name, parent node, slug, or icon URL.

  • Method: PUT
  • Path: /api/v1/admin/categories/{id}
  • Security: Requires CATALOG_WRITE
  • Path Variable: id (integer)

Success Response (200 OK)

Returns updated CategoryResponse object.

6. Admin: Toggle Status & Delete Category

  • Toggle Active Status: PATCH /api/v1/admin/categories/{id}/status?isActive=true → 204 No Content
  • Delete Category: DELETE /api/v1/admin/categories/{id} → 204 No Content

7. Admin: Export Categories CSV

Generates and downloads a CSV export file with UTF-8 BOM encoding containing filtered or all categories.

  • Method: GET
  • Path: /api/v1/admin/categories/export
  • Security: Bearer JWT (CATALOG_READ or CATALOG_WRITE)
  • Produces: text/csv; charset=UTF-8

Query Parameters

Parameter Type Required Description
search String No Search by category name or slug
isActive Boolean No Filter by active/inactive status
