Product Reviews & Ratings API

Base Path: /api/v1/reviews • /api/v1/products/{productId}/reviews

Target Service: joppe.backend.domain.interaction.ReviewService

Endpoints Specification

  • Get Product Reviews: GET /api/v1/products/{productId}/reviews • Security: Public (REVIEW_READ / permitAll)

    Returns verified customer ratings, review comments, and aggregate star distribution.

  • Submit Customer Review: POST /api/v1/products/{productId}/reviews • Security: Authenticated (REVIEW_CREATE)

    Allows verified purchasers to submit a star rating (1-5) and text feedback.

  • Moderate Review Visibility: PATCH /api/v1/admin/reviews/{id}/visibility • Security: Staff / Admin (REVIEW_MANAGE)

    Toggles visibility status of customer reviews.
