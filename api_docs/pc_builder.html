PC Builder & Hardware Compatibility API

Base Path: /api/v1/pc-builder

Target Service: joppe.backend.domain.interaction.PcBuildService

Endpoints Specification

  • Simulate Hardware Compatibility: POST /api/v1/pc-builder/simulate • Security: Public (PC_BUILD_SIMULATE)

    Evaluates hardware interoperability (CPU socket vs Motherboard socket, RAM DDR4/DDR5 standard, PSU wattage vs total GPU/CPU TDP, and cooler dimensions).

  • Save Custom Build: POST /api/v1/pc-builder/save • Security: Authenticated (PC_BUILD_MANAGE)

    Saves custom PC part configuration into customer account.

  • List Customer Builds: GET /api/v1/pc-builder/my • Security: Authenticated (PC_BUILD_MANAGE)
  • Add PC Build to Cart: POST /api/v1/pc-builder/{id}/add-to-cart • Security: Authenticated (CART_MANAGE)

    Transfers all compatible components of the saved build into the customer shopping cart.
