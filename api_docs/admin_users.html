Admin — User Management API

Base Path: /api/v1/admin/users

Controller: joppe.backend.admin.controller.AdminUserController

Security: All endpoints require USER_MANAGE authority

1. List Users

Lists user accounts across all roles with keyword search, role ID, and account status filtering.

  • Method: GET
  • Path: /api/v1/admin/users
  • Security: Requires USER_MANAGE

Query Parameters

Parameter Type Required Description
search string No Case-insensitive search matching full name, email, or phone number
roleId integer No Filter by system role ID (e.g. 1 for ADMIN, 2 for STAFF, 3 for CUSTOMER)
isActive boolean No Filter by active status (true or false)

Success Response (200 OK)

[
  {
    "id": "a50c82f8-0f0e-436b-a253-12502690d796",
    "email": "admin@joppe.vn",
    "fullName": "System Administrator",
    "phoneNumber": "0987654321",
    "avatarUrl": "/uploads/avatars/admin.webp",
    "roleId": 1,
    "roleName": "ROLE_ADMIN",
    "isActive": true,
    "createdAt": "2026-10-22T00:00:00.000Z"
  }
]

2. Get User by ID

Retrieves specific account profile and role details by user UUID.

  • Method: GET
  • Path: /api/v1/admin/users/{id}
  • Security: Requires USER_MANAGE
  • Path Variable: id (UUID)

Success Response (200 OK)

Returns a single UserSummaryResponse object matching the item schema above.

3. Create User Account

Manually provisions a new account with an assigned system role.

  • Method: POST
  • Path: /api/v1/admin/users
  • Security: Requires USER_MANAGE

Request Body

{
  "email": "staff_nv1@joppe.vn",
  "password": "StaffPassword123!",
  "fullName": "Tran Thi Staff",
  "phoneNumber": "0933112233",
  "roleId": 2
}

Field Validation Rules

Field Type Required Constraints
email string Yes Not blank, valid email format, unique
password string Yes Not blank, min 6 characters
fullName string Yes Not blank, max 150 characters
phoneNumber string No Max 20 characters
roleId integer Yes Must reference a valid existing role ID

Success Response (201 Created)

Returns created UserSummaryResponse.

4. Update User Account

Modifies user details, role assignment, and active status.

  • Method: PUT
  • Path: /api/v1/admin/users/{id}
  • Security: Requires USER_MANAGE
  • Path Variable: id (UUID)

Request Body

{
  "fullName": "Tran Thi Staff Updated",
  "phoneNumber": "0933998877",
  "avatarUrl": "/uploads/avatars/staff.webp",
  "roleId": 2,
  "isActive": true
}

Success Response (200 OK)

Returns updated UserSummaryResponse.

5. Activate / Suspend User Account

Quickly activates or suspends an account.

  • Method: PATCH
  • Path: /api/v1/admin/users/{id}/status
  • Security: Requires USER_MANAGE
  • Path Variable: id (UUID)

Request Body

{
  "isActive": false
}

Success Response (200 OK)

{
  "success": true,
  "message": "User account suspended"
}

6. Delete User Account

Permanently removes a user account from the system.

  • Method: DELETE
  • Path: /api/v1/admin/users/{id}
  • Security: Requires USER_MANAGE
  • Path Variable: id (UUID)

Success Response (200 OK)

{
  "success": true,
  "message": "User deleted successfully"
}
