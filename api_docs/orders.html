Customer Orders & Checkout API

Base Path: /api/v1/orders

Controller: joppe.backend.domain.order.OrderController

Security: Requires ORDER_CREATE or ORDER_READ_OWN

Business Flow & State Machine

  • Order Status Lifecycle: ACCEPTED → PACKAGING → DELIVERY → SHIPPED → REFUND (optional). Transitions advance step-by-step and cannot regress to lower states.
  • Online Orders: Initial status is automatically set to ACCEPTED with payment status PAID. Cannot regress to UNPAID.
  • Refund Eligibility Rule: An order cannot be refunded if more than 10 calendar days have elapsed since the payment date or successful delivery date (SHIPPED/DELIVERED).
  • Atomic Stock Management: On checkout, items execute reserveStock. On cancellation, reserved stock is released. On physical shipment/handover, physical stock is deducted.

1. Checkout / Place Order

Places an order from the active shopping cart (or explicitly provided variant items), validates stock, reserves inventory, and generates order code ORD-YYYYMMDD-XXXXX.

  • Method: POST
  • Path: /api/v1/orders/checkout
  • Security: Requires ORDER_CREATE

2. Customer Order History

  • Method: GET
  • Path: /api/v1/orders/my
  • Security: Requires ORDER_READ_OWN

Success Response (200 OK)

Returns an array of OrderSummaryResponse objects.

3. Customer Order Detail

  • Method: GET
  • Path: /api/v1/orders/{id}
  • Security: Requires ORDER_READ_OWN (ownership verified)
  • Path Variable: id (UUID)

Success Response (200 OK)

Returns full OrderResponse object with line items.

4. Customer Cancel Order

Cancels a pending order and releases reserved warehouse inventory.

  • Method: POST
  • Path: /api/v1/orders/{id}/cancel
  • Security: Requires ORDER_READ_OWN (must be in ACCEPTED or PENDING state)
  • Path Variable: id (UUID)

Success Response (200 OK)

Returns updated OrderResponse with orderStatus = CANCELLED.
