Payment Gateway & VNPAY Integration API

Base Path: /api/v1/payment/vnpay

Controller: joppe.backend.domain.order.vnpay.VnPayPaymentController

1. Generate VNPAY Checkout URL

Builds a signed VNPay payment gateway URL with HMAC-SHA512 checksum and creates a pending payment intent.

  • Method: POST
  • Path: /api/v1/payment/vnpay/create
  • Security: Authenticated (PAYMENT_PROCESS, ORDER_CREATE, or staff/admin)

2. Backend QR Code Image Stream

Generates and streams raw PNG image bytes for a payment URL or payment record on the backend.

  • Method: GET
  • Path: /api/v1/payment/vnpay/qr
  • Security: Public (permitAll)
  • Content-Type: image/png
  • Query Parameters:
    • paymentUrl (optional): Encoded payment gateway URL to encode into QR matrix
    • paymentId (optional UUID): Payment record identifier
    • size (optional integer, default 300): Width and height in pixels

3. VNPAY Instant Payment Notification (IPN Webhook)

Server-to-server webhook invoked asynchronously by VNPay to confirm transaction status.

  • Method: GET
  • Path: /api/v1/payment/vnpay/ipn
  • Security: Public (permitAll)

Webhook Responses

Condition RspCode Message
Success00Confirm Success
Order Not Found01Order not Found
Already Confirmed02Order already confirmed
Invalid Amount04Invalid Amount
Checksum Failed97Invalid Checksum

4. VNPAY Return URL Redirect Handler

Handles browser redirect when customer finishes or cancels payment on the gateway.

  • Method: GET
  • Path: /api/v1/payment/vnpay/return
  • Security: Public (permitAll)
  • Content Negotiation: Returns JSON result or HTML popup closer page depending on Accept header.
