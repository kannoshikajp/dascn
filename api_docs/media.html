Central Media Management API

Base Path: /api/v1/media • Static Asset URL: /uploads/**

Controller: joppe.backend.media.controller.MediaUploadController

Security: Upload & listing require authenticated session (isAuthenticated())

1. Upload Media File

Uploads a media image to the server disk and records metadata in the central uploaded_media table.

  • Method: POST
  • Path: /api/v1/media/upload
  • Security: Authenticated (isAuthenticated())
  • Content-Type: multipart/form-data

Form Parameters

Parameter Type Required Description & Constraints
file binary Yes Image file (JPEG, PNG, WebP, GIF, SVG). Maximum file size: 15MB.
folder string No Destination folder: products, descriptions, categories, brands, avatars, general (Default: general)

Success Response (201 Created)

{
  "id": "11111111-2222-3333-4444-555555555555",
  "fileUrl": "/uploads/products/1729584000000_rtx4080.webp",
  "fileName": "1729584000000_rtx4080.webp",
  "fileSize": 182420,
  "contentType": "image/webp",
  "folder": "products",
  "createdAt": "2026-10-22T08:00:00.000Z"
}

2. List Media Library

Lists stored media files with optional folder filtering and keyword search for easy asset re-use.

  • Method: GET
  • Path: /api/v1/media
  • Security: Authenticated (isAuthenticated())

Query Parameters

Parameter Type Required Description
folder string No Filter by folder name (products, categories, brands, descriptions, avatars, general)
search string No Keyword search matching original file name

Success Response (200 OK)

Returns an array of UploadResponse objects.

3. Public Asset Serving

Static uploaded assets are served directly through Spring Boot web resource handler:

  • Path Pattern: GET /uploads/**
  • Security: Public (permitAll)
