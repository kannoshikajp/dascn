Shopping Cart Management API

Base Path: /api/v1/cart

Controller: joppe.backend.domain.cart.CartController

Security: Requires CART_MANAGE authority. User identity resolved from JWT subject.

1. Get Active Cart

Retrieves the user's shopping cart, items, pricing, thumbnail, and subtotal amount.

  • Method: GET
  • Path: /api/v1/cart
  • Security: Requires CART_MANAGE

Success Response (200 OK)

2. Add Item to Cart

Atomically verifies available warehouse stock and increments line item quantity.

  • Method: POST
  • Path: /api/v1/cart/items
  • Security: Requires CART_MANAGE

Request Body

{
  "variantId": "22222222-3333-4444-5555-666666666666",
  "quantity": 1
}

Success Response (200 OK)

Returns updated CartResponse.

3. Update Item Quantity

Updates line item quantity. Passing quantity = 0 automatically removes the item.

  • Method: PUT
  • Path: /api/v1/cart/items/{itemId}
  • Security: Requires CART_MANAGE
  • Path Variable: itemId (UUID)

Request Body

{
  "quantity": 2
}

Success Response (200 OK)

Returns updated CartResponse.

4. Remove Item from Cart & Clear Cart

  • Remove Single Item: DELETE /api/v1/cart/items/{itemId} → 200 OK (Returns CartResponse)
  • Clear Entire Cart: DELETE /api/v1/cart → 200 OK (Returns empty CartResponse)

5. Merge Guest Cart on Login

Merges client-side anonymous shopping items into the authenticated customer's backend cart.

  • Method: POST
  • Path: /api/v1/cart/merge
  • Security: Requires CART_MANAGE

Request Body

{
  "items": [
    {
      "variantId": "22222222-3333-4444-5555-666666666666",
      "quantity": 1
    }
  ]
}

Success Response (200 OK)

Returns merged CartResponse.
