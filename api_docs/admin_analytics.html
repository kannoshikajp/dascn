Admin — Analytics & KPIs API

Base Path: /api/v1/admin/analytics

Controller: joppe.backend.admin.controller.AdminAnalyticsController

Security: Requires ORDER_MANAGE, CATALOG_READ, INVENTORY_READ, or staff/admin role

1. Get Store Overview Metrics

Aggregates revenue totals, 7-day sales velocity trend, inventory health status, recent orders, and user metrics for executive dashboard display.

  • Method: GET
  • Path: /api/v1/admin/analytics/overview
  • Security: Authenticated staff / admin
