Authentication & User Profile API

Base Path: /api/v1/auth

Controller: joppe.backend.auth.controller.AuthController

Token Format: Nimbus JOSE JWT with HmacSHA256 in Authorization: Bearer <token> header

1. Register Customer Account

Registers a new retail customer account, stores credentials securely, and automatically issues an active JWT session.

  • Method: POST
  • Path: /api/v1/auth/register
  • Security: Public (permitAll)
  • Headers: Content-Type: application/json, Accept: application/json

Request Body

{
  "email": "customer@example.com",
  "password": "Password123!",
  "fullName": "Nguyen Van A",
  "phoneNumber": "0901234567"
}

Field Validation Rules

Field Type Required Constraints & Rules
email string Yes Not blank, valid email format, max 100 characters, unique in database
password string Yes Not blank, minimum 6 characters
fullName string Yes Not blank, max 150 characters
phoneNumber string No Max 20 characters

Success Response (201 Created)

{
  "tokenType": "Bearer",
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresInSeconds": 86400,
  "userId": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "email": "customer@example.com",
  "fullName": "Nguyen Van A",
  "role": "ROLE_CUSTOMER",
  "permissions": [
    "AUTH_ME",
    "AUTH_CHANGE_PASSWORD",
    "USER_READ_SELF",
    "ADDRESS_MANAGE",
    "CATALOG_READ",
    "CART_MANAGE",
    "PROMOTION_READ",
    "ORDER_CREATE",
    "ORDER_READ_OWN",
    "PAYMENT_PROCESS",
    "RETURN_REQUEST",
    "REVIEW_CREATE",
    "PC_BUILD_MANAGE",
    "REVIEW_READ",
    "PC_BUILD_SIMULATE",
    "ORDER_TRACK_GUEST"
  ]
}

2. Login User

Authenticates an existing account (Admin, Staff, or Customer) with email and password credentials.

  • Method: POST
  • Path: /api/v1/auth/login
  • Security: Public (permitAll)
  • Headers: Content-Type: application/json, Accept: application/json

Request Body

{
  "email": "admin@joppe.vn",
  "password": "Admin@123456"
}

Success Response (200 OK)

Returns standard AuthResponse containing access token, user metadata, role, and permission array:

{
  "tokenType": "Bearer",
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresInSeconds": 86400,
  "userId": "a50c82f8-0f0e-436b-a253-12502690d796",
  "email": "admin@joppe.vn",
  "fullName": "System Administrator",
  "role": "ROLE_ADMIN",
  "permissions": [
    "AUTH_ME",
    "AUTH_CHANGE_PASSWORD",
    "USER_MANAGE",
    "ROLE_MANAGE",
    "CATALOG_READ",
    "CATALOG_WRITE",
    "INVENTORY_READ",
    "INVENTORY_WRITE",
    "ORDER_MANAGE"
  ]
}

Error Responses

  • 401 Unauthorized: Bad credentials (incorrect email or password).
  • 403 Forbidden: Account suspended or deactivated (isActive = false).

3. Get Current User Profile

Retrieves personal account information, avatar URL, active role, and granted permissions for the authenticated caller.

  • Method: GET
  • Path: /api/v1/auth/me
  • Security: Requires AUTH_ME authority
  • Headers: Authorization: Bearer <token>, Accept: application/json

Success Response (200 OK)

{
  "id": "a50c82f8-0f0e-436b-a253-12502690d796",
  "email": "admin@joppe.vn",
  "fullName": "System Administrator",
  "phoneNumber": "0987654321",
  "avatarUrl": "/uploads/avatars/admin.webp",
  "role": "ROLE_ADMIN",
  "permissions": [
    "AUTH_ME",
    "AUTH_CHANGE_PASSWORD",
    "USER_MANAGE",
    "ROLE_MANAGE",
    "CATALOG_READ",
    "CATALOG_WRITE"
  ],
  "isActive": true,
  "createdAt": "2026-10-22T00:00:00.000Z"
}

4. Update Current User Profile

Modifies profile name, contact phone number, and avatar image link for the authenticated caller.

  • Method: PUT
  • Path: /api/v1/auth/profile
  • Security: Requires AUTH_ME authority
  • Headers: Authorization: Bearer <token>, Content-Type: application/json

Request Body

{
  "fullName": "Nguyen Van B",
  "phoneNumber": "0912345678",
  "avatarUrl": "/uploads/avatars/avatar_updated.webp"
}

Field Validation Rules

Field Type Required Constraints
fullName string Yes Not blank, max 150 characters
phoneNumber string No Max 20 characters
avatarUrl string No Max 1000 characters

Success Response (200 OK)

Returns updated UserProfileResponse object.

5. Change Password

Updates account password after verifying current credentials.

  • Method: POST
  • Path: /api/v1/auth/change-password
  • Security: Requires AUTH_CHANGE_PASSWORD authority
  • Headers: Authorization: Bearer <token>, Content-Type: application/json

Request Body

{
  "currentPassword": "OldPassword123!",
  "newPassword": "NewPassword456!"
}

Success Response (200 OK)

{
  "success": true,
  "message": "Password changed successfully"
}
