Admin — RBAC Roles & Permissions API

Base Path: /api/v1/admin

Controller: joppe.backend.admin.controller.AdminRbacController

Security: All endpoints require ROLE_MANAGE authority

2. Get Role by ID

Retrieves specific role details and its complete permission list.

  • Method: GET
  • Path: /api/v1/admin/roles/{id}
  • Security: Requires ROLE_MANAGE
  • Path Variable: id (integer)

Success Response (200 OK)

Returns a single RoleDto matching the role item structure.

3. Create Role

Creates a new role definition with an initial set of assigned permission strings.

  • Method: POST
  • Path: /api/v1/admin/roles
  • Security: Requires ROLE_MANAGE

Request Body

{
  "roleName": "ROLE_WAREHOUSE_MANAGER",
  "description": "Staff in charge of stock imports and audits",
  "permissions": [
    "INVENTORY_READ",
    "INVENTORY_WRITE",
    "CATALOG_READ"
  ]
}

Success Response (201 Created)

Returns created RoleDto object.

4. Update Role Permissions

Overwrites the active set of permissions associated with an existing role.

  • Method: PUT
  • Path: /api/v1/admin/roles/{id}/permissions
  • Security: Requires ROLE_MANAGE
  • Path Variable: id (integer)

Request Body

{
  "permissions": [
    "CATALOG_READ",
    "INVENTORY_READ",
    "INVENTORY_WRITE"
  ]
}

Success Response (200 OK)

Returns updated RoleDto object.

5. Delete Role

Deletes a custom role from the database. Default seeded system roles cannot be deleted.

  • Method: DELETE
  • Path: /api/v1/admin/roles/{id}
  • Security: Requires ROLE_MANAGE
  • Path Variable: id (integer)

Success Response (200 OK)

{
  "success": true,
  "message": "Role deleted successfully"
}
